# Full JeV training and full Holmes test: preregistered protocol

- Data: all 48,126 questions of `/pfs/qcy/JeV-Data/video_multiple_choice_clean_48126.json` for training and all 1,837 questions of `/pfs/qcy/JeV-Data/holmes.json` for final test. Read source files only. Store all derived data, adapters, logs and results below `/pfs/hyx/videojev-rlcd`.
- Repair only JeV problem `9020007652`: its original `B. ).` option has no usable text after option-prefix stripping; represent it in the derived copy as `B. [missing option text]`. Preserve its gold answer A and record this change in the data manifest.
- Check question-ID, full-video-path and video-filename disjointness between JeV and Holmes. Partition JeV by video filename with seed 20261005 into folds of 24,063 questions each. Train answer model F0 on fold0 and predict fold1; train F1 on fold1 and predict fold0. This yields one out-of-fold greedy action and correctness label per JeV question. Neither fold model is trained on its predicted video's questions.
- Separately train the production answer adapter P on all 48,126 JeV questions. F0, F1 and P start from the same Qwen3.5-2B base with rank-8 language LoRA, restricted-choice action cross entropy, one pass, effective batch 8, cosine learning rate from 1e-5 to 1e-6. Use final one-pass weights, with no Holmes-based checkpoint selection.
- Train an independent rank-8 confidence LoRA from the base Qwen3.5-2B on all 48,126 out-of-fold frozen actions and correctness labels. Optimize `(E[q]-y)^2` over the ten existing confidence bins using effective batch 8, one pass and cosine learning rate from 2e-6 to 2e-7. This adapter cannot alter P's action. Its OOF labels approximate unseen-question correctness, but fold answer policies trained on half the data may differ from P trained on all data.
- Fit a two-parameter Platt baseline on the same OOF actions using their chosen-action softmax probabilities and correctness labels. It uses no Holmes labels.
- Run P on all Holmes questions once, then score its action with the confidence adapter and Platt on the same items. Report answer accuracy, mean q, Brier, AUC and the constant-oracle Brier `accuracy*(1-accuracy)`. Cluster bootstrap Brier differences by Holmes video filename. Holmes is never used for training, calibration, hyperparameters or checkpoint selection.
- Save complete model and optimizer checkpoints every 4,000 training examples for crash recovery; resume from the newest complete checkpoint. A final evaluation is valid only when all input and output row counts and model completion markers match.
