# Frozen-F0 joint action and confidence protocol

Start each student from the completed F0 answer LoRA trained on JeV fold0. Train a **single** LoRA to produce both `Action: <letter>` and `Confidence: <digit>`; at evaluation, its own greedy answer and conditional confidence digit are read from the same adapter. No Platt adjustment is applied to its output. The two autoregressive positions are scored sequentially with the same model; this is one model, not a claim of one literal matrix forward pass.

To avoid repeatedly selecting on the earlier 2,000-question sealed JeV set, make a fresh video-filename-disjoint split from the previous 20,063-question confidence-training pool: 16,063 train, 2,000 development, 2,000 newly reserved same-source test, seed 20261008. The split and hashes are in [the manifest](f0_joint_confidence_manifest.json). These questions are all unseen by F0. The earlier ablation LoRAs trained on this pool, but they are **not** used to initialize these students. Holmes remains the same previously inspected external test, so any Holmes result is a repeated evaluation, not a new blind test.

Use saved F0 action distributions and correctness labels on the 16,063 training questions. Fit a two-parameter Platt function on only those questions, with the established 1e-4 slope penalty, to supply a continuous **training-only teacher** `q_teacher`. For each student, minimize

`(E[q] - y)^2 + λ(E[q] - q_teacher)^2 + 5 KL(p_F0(Action) || p_student(Action))`.

Here `E[q]` is the expected probability over the ten confidence digits, conditioned on F0's selected action during training. `p_F0(Action)` is the entire restricted-choice distribution cached from F0; the KL term anchors the student's action distribution to F0. The fixed KL coefficient is 5.0. Run three teacher weights, λ = 0, 0.5 and 1, at the previously favorable cosine learning rate 2e-5 → 2e-6, effective batch 8, one epoch, with checkpoints at 4,000, 8,000, 12,000, 16,000 and 16,063 questions. No new answer model is trained.

On the 2,000-question development set, **use the student's own greedy action and confidence**. For each teacher weight, evaluate every checkpoint. A checkpoint is eligible only if it matches F0's action on at least 99% of development questions and its action accuracy is no lower than F0's. Choose the eligible checkpoint with lowest direct-mean-confidence Brier for each weight, then the eligible weight with lowest development Brier. If none is eligible, select the lowest-Brier checkpoint for diagnosis only and do not promote it. The direct argmax-digit confidence and the student's chosen-answer softmax probability are secondary readouts; they receive no postprocessing.

After writing the development-only selection, evaluate only the selected student on the fresh 2,000-question JeV test and all 1,837 Holmes questions. Report action agreement with F0, action accuracy change, confidence Brier/AUC/ten-bin ECE, and the direct argmax-digit readout. Compare with the unchanged F0's raw chosen-answer probability and Platt score as references. Video-cluster bootstrap intervals assess differences in Brier and action accuracy. The student must retain F0's accuracy and agreement to be considered for use; the KL penalty alone cannot guarantee this. All remote writes remain under `/pfs/hyx/videojev-rlcd`.
